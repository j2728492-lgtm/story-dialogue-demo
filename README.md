# 夜航书店 · 故事对话界面样例

可操作的中文静态界面：纸间与夜读两种样式、三条固定剧情分支、时间/关系/天气状态、长短正文、本地输入和重置。桌面及窄屏布局已检查。

将本目录用任意静态服务器打开，或下载后打开 index.html。无依赖安装、付费 API、数据库和外部字体。故事与角色均为虚构；插画由图像生成工具制作。输入仅保存在当前页面内存。

这是独立概念作品，不是客户上线案例，也未接入模型或 SillyTavern。点击选项演示预设故事；输入用于展示自己的文本，不会生成新剧情。

验证范围见 [QA.md](QA.md)。本次公开打包仅将插画移到根目录并同步图片路径；未改变交互逻辑。手机检查为浏览器视口模拟，未做 iPhone 真机或 Safari 验证。
